# PDF RAG Chatbot

A Retrieval-Augmented Generation chatbot using:

- FAISS
- sentence-transformers
- TinyLlama
- pypdf

Runs locally in Google Colab.

## Features

- PDF ingestion
- Semantic search
- Local LLM inference
- Vector database retrieval

## Tech Stack

- Python
- Transformers
- FAISS
- Sentence Transformers
